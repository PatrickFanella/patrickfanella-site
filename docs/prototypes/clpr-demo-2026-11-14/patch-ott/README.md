# Patch OTT (kept, 2026-11-14)

The owner liked this over-the-top version and asked to keep it before exploring new concepts.
It applies the selected Patrick__Eff "Patch / routed signal" brand
(`subcult-tv/studio/brands/patrick__eff`) at full volume to the prototype's content:
rack-module windows with screws, LEDs and hard offset shadows; patch-jack navigation; a canvas
stage of brand-style cables whose pulses replay the recorded round trips; a spectrum band from the
measured durations; an oscilloscope plan chart; VU-meter timings; scanlines and glow.

Reference only, like the rest of this folder. `build-ott.mjs` imports `render.mjs`, `cases.mjs`
and `recorded.json` from the parent folder's prototype and expects `node_modules` with PGlite and
the three Fontsource variable fonts. `mark.svg` is the brand's approved 01 Lavender waveform mark.
