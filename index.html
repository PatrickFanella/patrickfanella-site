What's coming

The finished site is a set of working pieces, built in this order. Each one runs in your browser, so you can check the claim yourself.

The current portfolio stays up until they're done.

  1. 1 The deskA tiling terminal desktop that boots in your tab. Prototype running

    PostgreSQL 18.6 starts in the browser, loads 50,008 clips from Clpr and runs its search query twice: once reading every row, once through the full-text index. The timings on screen are measured on your machine, just then. There's a shell you can type into, and the panes sit on this same ink.

    Runs on: PGlite (PostgreSQL compiled to WebAssembly) in a worker, WebGL2.

  2. 2 Clpr, running liveMy production search code answering your searches. Proven in a spike

    Clpr's own Go search handler, compiled to WebAssembly, talks to that in-browser database through the same driver it uses in production. You search; you see the SQL it sent, the query plan and the round trip, byte by byte.

    The spike works today at 9.3 MB compressed. It ships once it's under 6 MB.

  3. 3 Read the codeCase studies set beside the real source. Planned

    Each case study is the actual code, pinned to a commit, with notes on the lines that matter: why it's written that way, what it costs and what I'd change. The first one walks through how Clpr ranks and pages its search results.

  4. 4 The projectsEverything from the current site, moved over. Moving over

    The 25 projects on the current portfolio, each with what it is, how it's built and how far along it is. Nothing in development will be described as finished.

  5. 5 One way of movingA shared set of transitions and interactions. In progress

    Every page will move the same way: letters that pour, links that bleed ink, presses that splash, rows that unfold in place and pages that hand over to each other. You're looking at the first version. Each one has a reduced-motion version that leaves the page complete and still.
