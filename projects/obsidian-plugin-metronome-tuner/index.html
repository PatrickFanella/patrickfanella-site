Metronome + Tuner

An Obsidian metronome and chromatic tuner using Web Audio, with keyboard controls and explicit microphone opt-in.

Status
Desktop and mobile plugin
Role
Plugin developer
Period
2026
Repository

Product and scope

I built an in-vault practice tool with a metronome, chromatic pitch display and configurable tuning reference. Audio analysis stays on the device; microphone access starts only after the musician explicitly enables it.

Stack
TypeScript, Web Audio, Obsidian

The problem

A small music tool needs dependable timing and a clear boundary around microphone access.

What I built

  • Built tempo, meter and accent controls alongside a chromatic tuner.
  • Added keyboard interaction, local settings and explicit microphone consent.

How it fits together

Web Audio drives the click and pitch analysis inside the Obsidian runtime. Device and mobile-host microphone behavior can differ.

What I learned

  • Permission state is part of the interaction, not a prerequisite to silently assume.
