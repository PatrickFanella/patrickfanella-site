Stupen

A practice coach with learner-controlled assistance, a coding workspace and isolated execution for hands-on exercises.

Status
Unreleased; invited learners
Role
Backend and full-stack engineer
Period
2026–present
Visit Stupen Repository

Product and scope

I built the learning workflow, coach interface and exercise execution boundaries. Learners choose how much help to receive and connect their own model accounts. Run supports practice; Submit records canonical assessment and history.

Stack
TypeScript, React, Node.js, WebAssembly, Docker, Linux sandboxing

The problem

Generated lessons need observable checks, and learner code must be separated from the application host.

What I built

  • Built lesson, editor, feedback and private history flows.
  • Separated practice from assessment and added a remote sandbox runner protocol.

How it fits together

The app and runner advertise compatible capabilities. An unavailable runner disables practice instead of executing learner code on the app host.

What I learned

  • UI fixtures prove state handling, while real runner tests prove execution. Model behavior and learning outcomes require separate evaluation.
