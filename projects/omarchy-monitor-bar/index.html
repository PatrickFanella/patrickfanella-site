Omarchy Multi-Monitor Bar

A separate Omarchy bar layout for each connected monitor.

Status
Tool
Role
Plugin developer
Period
2026
Repository

Product and scope

Give each monitor its own bar: Full, Minimal or Hidden, with the primary monitor locked to Full. Minimal bars show a glyph and the workspace list. A settings panel validates changes and checks the plugin against the stock Omarchy bar files it is pinned to. Ten languages.

Stack
QML, Quickshell, Python

The problem

A shared bar layout cannot distinguish the primary monitor from secondary monitors. Each monitor needs its own layout while one primary monitor keeps the Full bar.
