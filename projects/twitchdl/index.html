twitchdl

A Go CLI for downloading public Twitch clips and VODs and recording live streams. It orchestrates yt-dlp, Streamlink, and ffmpeg; discovery, scheduling, and authenticated content are deferred.

Status
Functional CLI
Role
Media tooling engineer
Period
2026
Repository

Product and scope

twitchdl accepts public URLs and channel names, supports bounded live recording, and checks the external media tools it needs. Its application layer is designed to support a future terminal interface.

Stack
Go, yt-dlp, Streamlink, ffmpeg

The problem

Clip downloads, ranged VODs, and bounded live recordings need consistent command behavior across several external media tools.

What I built

  • Built Go commands for public Twitch clips, VODs, and bounded live recording.
  • Orchestrated yt-dlp, Streamlink, and ffmpeg behind a shared application layer.
  • Checked external tool dependencies before starting media operations.
