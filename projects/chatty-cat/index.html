Chatty Cat

A self-hosted Twitch workspace with merged and independent chat panes. I built Go chat services, a TypeScript interface, and permission-checked account actions.

Status
Public preview
Role
Design and engineering
Period
Active in 2026
Visit Chatty Cat Download source

Product and scope

Chatty Cat rebuilds mxmilkiib’s HasanAbi Chat Thing and Twitch relay as a Go service with a TypeScript frontend. Configurable workspaces support anonymous reading and Twitch-authenticated sending, replies, and whispers. Chat transport, public history, and optional context providers have separate failure boundaries.

Stack
Go, TypeScript, Twitch IRC, WebSocket, IndexedDB

The problem

A busy community needs readable chat and useful context without losing its place when a connection drops.

What I built

  • Built merged and independent channel panes with saved display settings, emotes, filters, and local workspace state.
  • Keep OAuth credentials server-side and check account permissions for sends, replies, and whispers.
  • Reconnect and restore available public history while keeping optional provider failures separate from chat transport.

How it fits together

A Go service handles Twitch transport and bounded provider caches; the TypeScript frontend owns workspace presentation.

Local worker-backed storage keeps statistics work separate from the main UI thread.
