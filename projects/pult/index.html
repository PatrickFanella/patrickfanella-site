Pult

A Go terminal app that applies one palette across installed applications with previewable changes, ownership checks and recovery.

Status
Early 0.x tool
Role
Backend and full-stack engineer
Period
2026–present
Visit Pult Repository

Product and scope

I built a theme application pipeline that plans file changes, records originals and can recover an interrupted run. Pult uses an application’s own theme mechanism where possible and recognizes configuration owned by other tools.

Stack
Go, Terminal UI, Linux, macOS

The problem

Changing colors should not destroy unrelated settings or another manager’s files.

What I built

  • Built a theme catalog, application adapters and a searchable terminal interface.
  • Added dry-run diffs, journaling, undo and interrupted-run recovery.

How it fits together

Adapters create a concrete file plan. A journal and compressed original files support rollback and uninstall.

What I learned

  • The recovery path is part of the feature. Writing a valid configuration is only half of a configuration tool.
