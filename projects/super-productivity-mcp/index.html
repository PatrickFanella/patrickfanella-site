Super Productivity MCP

A Go MCP server, in-app bridge and quick-add tool connecting assistants to a local task manager through explicit contracts.

Status
v0.2.0; live v20 qualification incomplete
Role
Product and integration engineer
Period
2026–present
Repository

Product and scope

I built the MCP suite and its shared task contracts. Scopes constrain each client’s access, and scheduling tools can preview changes before applying them. Current v20 compatibility evidence comes from fixtures and CI; the documented live desktop qualification is still incomplete.

Stack
Go, JavaScript, MCP, JSON Schema

The problem

An assistant needs predictable task semantics and a reviewable boundary before it changes a person’s schedule.

What I built

  • Built the MCP server, plugin bridge and quick-add command.
  • Added contract checks, scoped tools and preview/confirmation for supported bulk operations.

How it fits together

Typed tool contracts bridge an assistant client to the locally running Super Productivity application. Preview behavior is explicit per tool.

What I learned

  • A fixture matching the upstream API is useful evidence, but it does not replace testing the installed desktop application.
