The Subculture Collective's public catalog of projects, tools, media, and infrastructure for independent digital culture.

Product and scope

Subcult.tv gives the Subculture Collective one public home for its identity, project catalog, tools, and media. The TypeScript site uses Docker and Make for local and deployment workflows.

Stack
TypeScript, React, Vite, Docker, Content, Brand System

The problem

The collective's work spans many repositories. Without a maintained public index, visitors lose the context connecting those projects.

What I built

  • Built SUBCULT's public catalog across projects, tools, media, and infrastructure.
  • Packaged the site with Docker and Make workflows used by the collective's other services.
  • Created a catalog-style entry point for the collective rather than scattering project context across repos.

How it fits together

The TypeScript web application keeps public pages, project content and the collective's own description in one repository.

Dockerized deployment keeps the public site aligned with the operational pattern used by other SUBCULT services.

The content model links projects, tools, and infrastructure in one catalog.

What I learned

  • Without a maintained index, the context connecting the collective's projects ends up scattered across repositories.
  • The public site is easier to maintain when it builds and deploys the same way as the application code.
