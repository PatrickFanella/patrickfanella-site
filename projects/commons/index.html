Commons

A discovery and collaboration hub with software comparisons, builder profiles, and discussions. Repository ownership checks gate project-management workflows.

Status
Public preview
Role
Design and engineering
Period
Active in 2026
Visit Commons

Product and scope

Commons brings project discovery, an alternatives index, builder profiles, repository ownership claims, progress updates, and threaded discussions into one application. Curated upstream references are distinguished from projects claimed by community members.

Stack
JavaScript, Node.js, React, SQLite

The problem

People rebuilding familiar tools need a place to find existing work and coordinate their contributions.

What I built

  • Built project discovery and software comparisons with source and maturity notes.
  • Required repository ownership proof before granting project-management capabilities.
  • Separated member activity and account-owned projects from imported reference listings.

How it fits together

The server persists accounts, projects, claims, and discussions in SQLite.

Recovery keys and optional verified-email recovery have separate authority; a public email address alone is not an ownership claim.
