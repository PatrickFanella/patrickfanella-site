Patchwork

An AT Protocol mutual-aid demonstration with ingestion, neighborhood discovery, moderation and approximate-location privacy.

Status
Pre-alpha demonstration
Role
Full-stack engineer
Period
2025–present
Visit Patchwork Repository

Product and scope

I built public-record ingestion, query workflows and the web interface around decentralized requests and offers. Public discovery uses an approximate location; finer disclosure is a separate, authorized step. The demo is not approved for arranging real help.

Stack
TypeScript, React, Node.js, PostgreSQL, AT Protocol

The problem

Public discovery needs useful geographic context without exposing a person’s exact location.

What I built

  • Built ingestion, indexing and neighborhood query paths.
  • Built moderation and explicit privacy boundaries for requests and offers.

How it fits together

Separate services ingest public records, serve queries and perform moderation. The interface distinguishes public information from approved disclosure.

What I learned

  • A functioning demonstration does not establish that a service is ready to coordinate real-world help.
